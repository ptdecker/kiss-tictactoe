## Phase Goal

**As a** player sitting at the desktop app, **I want to** have the engine trash talk me after game events and keep a running score across games with New Game and Reset Scores controls, **so that** the match feels like a game against a personality worth beating rather than a bare board.

<objective>
Vertical slice 1 (engine half of "the engine greets you and taunts the result"): the engine crate gains a voice that any interface can use. Adds the `TalkEvent` type (all 8 categories), the `Commentator` with a seeded std-only PRNG and the 4-8 line banks (ENGI-07, D-06 to D-09), and `Game::play` returning a `Turn { result, event }` that carries the game-over event (ENGI-05 lifecycle: engine wins / user wins / draw; game start is drawn by the caller on new game per D-05). Also fixes TD-02.

Slice note (MVP mode): the Dioxus side of this slice ships in 03-02. Engine and UI are split into separate plans only for context budget (13 files in one plan exceeds the per-plan budget); after this plan the capability is real and usable through the engine's public API, proven by the end-to-end integration test in Task 1. Tactical events (ENGI-06) land in 03-03 by extending the same `play` call.

Purpose: Every later slice (bubble, tactical talk, scoreboard) consumes `Game::play` and `Commentator`.
Output: commentary.rs, events.rs, TalkEvent in types.rs, Turn + Game::play in game.rs, lib.rs re-exports, extended tests/gameplay.rs.
</objective>
