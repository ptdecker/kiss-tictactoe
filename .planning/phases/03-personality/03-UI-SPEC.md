## New CSS Custom Properties (add to `:root`)

Existing Phase 2 tokens are unchanged. Add:

```css
:root {
  /* Color — Phase 3 */
  --color-bubble-bg: #FFFFFF;
  --color-bubble-border: #1E293B;          /* same value as --color-grid */
  --color-button-primary-bg: #1E293B;      /* same value as --color-text */
  --color-button-primary-text: #F9FAFB;    /* same value as --color-bg */
  --color-button-secondary-border: #94A3B8;
  --color-button-secondary-text: #475569;
  --color-score-label: #475569;

  /* Layout — Phase 3 */
  --bubble-min-height: 80px;               /* 2 lines x 24px (16px * 1.5) + 2 x --space-md padding */
  --bubble-tail-size: 8px;
  --bubble-border-width: 2px;
  --button-min-height: 44px;
  --button-border-width: 1px;
  --radius-bubble: 16px;

  /* Motion — Phase 3 */
  --bubble-fade-duration: 5s;
}
```

Contrast (WCAG AA, 4.5:1 minimum):
- `#1E293B` on `#FFFFFF` (bubble text): ~14.6:1, AAA
- `#475569` on `#F9FAFB` (score labels, secondary button text): ~7.1:1, AAA
- `#F9FAFB` on `#1E293B` (primary button): ~14.5:1, AAA
- `#94A3B8` secondary button border is decorative (text carries meaning); no text-contrast requirement.

## Layout

Single centered column (`.game-container`, `gap: var(--space-lg)`, max-width `--board-max`). New order (D-10, D-17):

1. `h1.app-title` — "Tic-Tac-Toe"
2. `.speech-bubble` — fixed reserved height
3. `.board-wrapper` — board and Phase 2 overlay (unchanged)
4. `.scoreboard` — one compact row
5. `.controls` — New Game + Reset Scores row

Focal point: the board remains dominant; the bubble is the secondary anchor and the only element that animates.

### Speech bubble (`SpeechBubble` component)

```
.speech-bubble:
  position: relative
  width: 100%                         /* fills container, max 360px */
  min-height: var(--bubble-min-height)  /* ALWAYS reserved, even when empty or faded */
  padding: var(--space-md)
  background-color: var(--color-bubble-bg)
  border: var(--bubble-border-width) solid var(--color-bubble-border)
  border-radius: var(--radius-bubble)
  color: var(--color-text)
  font-size: var(--font-size-body); font-weight: 400; line-height: 1.5
  text-align: center
  display: flex; align-items: center; justify-content: center

.speech-bubble::before / ::after  (tail):
  bottom-center, pointing DOWN toward the board
  CSS border triangle, size var(--bubble-tail-size); ::before draws the border color,
  ::after draws --color-bubble-bg one border-width inward so the outline is continuous
  position: absolute; left: 50%; top: 100%; transform: translateX(-50%)
```

Tail choice (default, not asked): centered, pointing down at the board (the engine "speaks" to the board it plays on). Tail overhangs into the container gap (24px > 8px), so no layout shift.

Fade behavior (D-11), CSS only:

```
@keyframes bubble-fade {
  0%, 80% { opacity: 1; }   /* hold 4s, fade over the last 1s; literals required in keyframes */
  100%    { opacity: 0; }
}
.speech-bubble--fading { animation: bubble-fade var(--bubble-fade-duration) linear forwards; }
.speech-bubble--final  { animation: none; opacity: 1; }   /* game-over message never fades */
```

Implementation notes for the planner:
- Keyframe percentages are literals (`var()` is invalid in keyframe selectors); only the duration is a token.
- Restart on a new message: render the bubble inner element with a Dioxus `key` derived from a monotonically increasing message counter (or remount the element), so the browser restarts the animation. Do not use a Rust timer.
- The bubble box (border, background, tail) fades together with the text via the `opacity` on `.speech-bubble`; its reserved height remains, so the board never moves.
- Empty/initial state before the first greeting: bubble rendered with `visibility: hidden` and the same min-height. In practice the game-start greeting (D-05) fires on launch, so the bubble is populated from first paint.
- Final (game-over) message: class `speech-bubble--final`, stays at full opacity until New Game / Play again.
- Message length: write bank strings at 64 characters or fewer so they fit two lines at 296px inner width (320px viewport: 288px inner). Longer text is clamped, never grows the box.
- `prefers-reduced-motion: reduce`: keep the fade (opacity only, no movement); no additional handling required.

Accessibility: `.speech-bubble` has `role="status"` and `aria-live="polite"` so new lines are announced; fading does not remove text from the DOM.

### Scoreboard (`Scoreboard` component)

```
.scoreboard:
  display: flex; flex-direction: row; justify-content: space-between
  width: 100%
  gap: var(--space-md)

.score-item:
  display: flex; flex-direction: column; align-items: center
  flex: 1 1 0
  gap: var(--space-xs)

.score-count: font-size var(--font-size-heading); weight 700; line-height 1.2; color var(--color-text)
.score-label: font-size var(--font-size-body); weight 400; line-height 1.5; color var(--color-score-label)
```

Order left to right: Wins, Draws, Losses (player perspective, D-17). Three equal columns; fits 288px of 320px viewports (each column ~85px, "Losses" at 16px is ~50px). No emphasis color on any column (default; counts are neutral so the board's X/O accents stay unique). Counts render as plain integers starting at `0`.

### Controls (`Controls` component)

```
.controls:
  display: flex; flex-direction: row; justify-content: center
  gap: var(--space-sm)
  width: 100%

.btn (shared):
  font-family: inherit; font-size: var(--font-size-body); font-weight: 400; line-height: 1.5
  min-height: var(--button-min-height)
  padding: var(--space-sm) var(--space-md)
  border-radius: var(--radius-pill)
  cursor: pointer
  flex: 1 1 0                      /* equal width, wraps text never; fits 288px */

.btn--primary  (New Game):
  background-color: var(--color-button-primary-bg); color: var(--color-button-primary-text)
  border: var(--button-border-width) solid var(--color-button-primary-bg)

.btn--secondary (Reset Scores), quiet:
  background-color: transparent; color: var(--color-button-secondary-text)
  border: var(--button-border-width) solid var(--color-button-secondary-border)
```

States (both buttons):

| State | New Game (primary) | Reset Scores (secondary) |
|-------|--------------------|--------------------------|
| Default | filled dark | transparent, grey border and text |
| Hover | `opacity: 0.9` | `border-color` and text color change to `--color-text` |
| Focus-visible | `outline: 2px solid var(--color-x)`, `outline-offset: 2px` | same |
| Active | `opacity: 0.8` | `opacity: 0.8` |
| Disabled | never disabled | never disabled (resetting at 0/0/0 is a harmless no-op) |

Note: the focus ring uses `--color-x` as the single accessibility exception to the accent list. Add `--focus-ring-width: 2px` and `--focus-ring-offset: 2px` to `:root` rather than hard-coding.

### Phase 2 overlay coexistence (D-12)

`GameOverOverlay` is unchanged: result text ("You win!" / "Engine wins!" / "Draw!") and "Play again" stay inside the board overlay. The bubble sits above the board and is not covered by the overlay (overlay anchors to `.board-wrapper`). At game over the bubble shows the final taunt (`speech-bubble--final`). Scoreboard and controls remain visible and usable beneath the overlay.

## Interaction Contract

| Interaction | Trigger | Response |
|-------------|---------|----------|
| Player move | Click empty cell | Board updates (X, then O). Exactly one bubble message for the turn (D-03); bubble shows it at full opacity and its 5s fade restarts. If no event, bubble is left as-is (fade continues) |
| Bubble fade | 5s after a message appears | Opacity 1 to 0 over the last second; box stays reserved; no layout shift |
| Game over | Win or draw detected | Overlay appears (Phase 2); bubble shows final taunt and does NOT fade; tally increments exactly once |
| New Game (button or Play again) | Click | Fresh `Game`; overlay cleared; bubble shows greeting and restarts fade; tally unchanged; mid-game discard is not a loss |
| Reset Scores | Click | Tally set to 0 / 0 / 0 immediately; game in progress, board and bubble untouched |
| Keyboard | Tab to buttons, Enter/Space | Native `button` behavior; visible focus ring |

Timing: no spinners or delays; engine reply remains instant. The only animation is the bubble opacity fade.

## Responsive (UI-06)

- Column remains `width: 100%`, `max-width: var(--board-max)`; bubble, scoreboard and controls span the column.
- At 320px: inner width is 288px. Bubble inner text width is 252px (after 16px padding and 2px border each side), about 30 characters per line, so bank strings stay at or under 56 characters.
- Controls: two equal-width buttons at about 140px each; "Reset Scores" at 16px (~95px text + 32px padding) fits without wrapping.
- The existing `@media (max-width: 360px)` rule is unchanged; no new breakpoints.
