## Phase Goal

**As a** player sitting at the desktop app, **I want to** have the engine trash talk me after game events and keep a running score across games with New Game and Reset Scores controls, **so that** the match feels like a game against a personality worth beating rather than a bare board.

<objective>
Vertical slice 2: tactical trash talk. After this plan the engine reacts mid-game: it gloats when it has two in a row, needles the user when the user threatens a win (seen before the engine's block, D-04), and judges the user's move as good or bad by minimax (D-02), one message per turn by fixed priority (D-03). Because 03-02 routes every `Turn.event` into the speech bubble, these lines show up in the app with no UI change; this plan runs in parallel with 03-02 (disjoint files) and both are present before the phase checkpoint in 03-04. Uses the tactical banks already created in 03-01 (ENGI-07). Folds in TD-03 and TD-04.

Purpose: Delivers ENGI-06 (ROADMAP criterion 2).
Output: threat detection + classify in events.rs, move_quality in ai.rs, extended Game::play, tactical end-to-end tests.
</objective>
