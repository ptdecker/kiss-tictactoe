<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Cell clicks -> `Game::play` | UI events mutate engine state only through `play` (validated guards) |
| Engine strings -> webview DOM | Bubble text is engine-owned `&'static str` rendered by rsx |
| System clock -> PRNG seed | Untrusted-but-harmless seed source |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-05 | Tampering | `Board` click handler | mitigate | Result is no longer discarded: `debug_assert!(outcome.is_ok())` and only `Ok(turn)` reaches `on_turn` (TD-01); positions still come only from `board_cells` |
| T-03-06 | Tampering / Injection | `SpeechBubble` text rendering | mitigate | Text rendered as an rsx text node (auto-escaped), never via `dangerous_inner_html`; acceptance grep on speech_bubble.rs has no `dangerous_inner_html` (verified at 03-04 phase gate) |
| T-03-07 | Denial of Service | `BubbleState.serial` overflow | mitigate | `wrapping_add` with a unit test at `u32::MAX` |
| T-03-08 | Denial of Service | Signal borrow conflict panic in handlers | mitigate | One signal write per statement; `bubble()` copied out before `bubble.set`; `game.write().play(p)` guard dropped before `on_turn.call` |
| T-03-09 | Information Disclosure | clock seed | accept | Seed only picks cosmetic lines |
</threat_model>
