# The engine's personality

The engine talks to you in a speech bubble above the board. It greets you when a game starts, reacts when you or it have two in a row, comments on good and bad moves, and has the last word when the game ends.

Each line is picked at random from a small set, so you rarely see the same line twice in a row. A new line replaces the old one. Normal lines fade away after a few seconds, while the game-over line stays until you start a new game. If your system asks for reduced motion, lines appear without the fade.

The tone is sharp and sarcastic, never personal.

Developers who want to know how the lines are chosen can see the Event system chapter of the engine manual in docs/engine.
