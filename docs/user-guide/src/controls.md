# Controls

## Clicking a cell

Click an empty cell to place your X. The engine replies immediately.

## New Game

Starts a fresh board with a new greeting from the engine. You can use it at any time. Your scores are unchanged, and leaving a game unfinished is not counted as a loss.

## Reset Scores

Sets Wins, Draws and Losses back to 0 immediately, with no confirmation. The current game and the speech bubble are left alone.

## Play again

Appears on the overlay when a game ends. It does the same thing as New Game.

## Scoring

Exactly one count goes up when a game ends. Scores last only for the current session: they are not saved, and they start from 0 each time you open the app.
