# Introduction

kiss-tictactoe is a tic-tac-toe game where you play X against an engine that never loses and trash talks you along the way. It can also teach you how to play better.

This guide is for anyone who wants to play the game. Version 1 runs on macOS only.

Developers who want to build on the game engine should read the Engine Manual (in `docs/engine`).

## About this project

This guide was written with Claude, an AI model made by Anthropic, and so was the game it describes. Claude wrote much of the code, tests and documentation under the direction and review of the project's author.
